Procrustes formulation of the Bures distance

Proved in LeanPapers.WassersteinRegretS2S3.buresProcrustes

Manuscript statement

For all A,B∈S+d​, we have
B(A,B)=U∈Odmin​∥A21​−B21​U∥F​=S,T∈Rd×dA=SS⊤,B=TT⊤​min​∥S−T∥F​.
Thus, B(A,B)≤ε if and only if there exists Δ∈Rd×d with ∥Δ∥F​≤ε such that A=(B1/2+Δ)(B1/2+Δ)⊤. The minimum is attained by U=Id​ if A and B are simultaneously diagonalizable.

Formal statement

Exact signature from the verified source. Open the proof to follow each dependency.

lemma buresProcrustes {n : ℕ} (A B : PSD n) :
    IsLeast {v : ℝ | ∃ U : Orth n, frob (CFC.sqrt A.val - CFC.sqrt B.val * U.val) = v}
      (buresDistance A.val B.val) ∧
    IsLeast {v : ℝ | ∃ S T : Mat n n, A.val = S * S.transpose ∧ B.val = T * T.transpose ∧
      frob (S - T) = v} (buresDistance A.val B.val) ∧
    (∀ eps : ℝ≥0, buresDistance A.val B.val ≤ eps ↔
      ∃ Delta : Mat n n, frob Delta ≤ eps ∧ -- @realizes \bDelta(real full matrix)
        A.val = (CFC.sqrt B.val + Delta) * (CFC.sqrt B.val + Delta).transpose) ∧
    ((∃ U : Orth n, ∃ a b : Fin n → ℝ,
      A.val = U.val * Matrix.diagonal a * U.val.transpose ∧
      B.val = U.val * Matrix.diagonal b * U.val.transpose) →
      frob (CFC.sqrt A.val - CFC.sqrt B.val) = buresDistance A.val B.val)
