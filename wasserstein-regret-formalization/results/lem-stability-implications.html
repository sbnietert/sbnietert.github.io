Manuscript statement

Let P∈P∗ and ε>0. We then have
Rε​(MROε​,P)≲κP​ε2,​
R_ε(SNR_ε,P) ≲ κP ε2. In contrast, our ERM and DRO guarantees adapt to the largest condition number in a ball around P:
Rε​(ERM,P)≲Q∈Bε​(P)sup​κQ​ε2
R_ε(DRO_ε,P) ≲ supQ ∈ B2ε(P) κQ ε2 If ε2≤λmin​(ΣXP​)/16, then these two upper bounds are at most O(κP​ε2).

All minimizer selections. The estimator variables are arbitrary. IsPopulationSelection requires an estimator to choose a minimizer at each law. The theorem applies to every rule satisfying that requirement, with no uniqueness or tie-breaking assumption. See the selection definitions.

Convention made explicit. This result carries the Euclidean-norm convention used by the manuscript. The formalization proves that convention in assPin1_valid. The singular-value convention is proved in assSingularValueConvention_valid. Both are included in the axiom audit.

Formal statement

Exact signature from the verified source. Open the proof to follow each dependency.

lemma stabilityImplications :
    ∃ C : ℝ, 0 < C ∧ ∀ (p m : ℕ) [NeZero p] [NeZero m],
      assPin1 m → assSingularValueConvention → ∀ (P : NondegenerateLaws p m)
      (eps : ℝ≥0), 0 < eps → ∀ erm dro mro snr : Estimator p m,
      IsPopulationSelection 0 eps erm → IsPopulationSelection 1 eps dro →
      IsPopulationSelection 2 eps mro → IsPopulationSelection 3 eps snr →
      robustRegret mro P.carrier.val eps ≤ ENNReal.ofReal C * conditionNumber P.carrier.val *
        (eps : ℝ≥0∞) ^ 2 ∧
      robustRegret snr P.carrier.val eps ≤ ENNReal.ofReal C * conditionNumber P.carrier.val *
        (eps : ℝ≥0∞) ^ 2 ∧
      robustRegret erm P.carrier.val eps ≤ ENNReal.ofReal C * (eps : ℝ≥0∞) ^ 2 *
        (⨆ Q ∈ lawBall P.carrier.val eps, conditionNumber Q) ∧
      robustRegret dro P.carrier.val eps ≤ ENNReal.ofReal C * (eps : ℝ≥0∞) ^ 2 *
        (⨆ Q ∈ lawBall P.carrier.val (2 * eps), conditionNumber Q) ∧
      (assStabilityImplicationsSmallRadius P.carrier.val eps →
        ENNReal.ofReal C * (eps : ℝ≥0∞) ^ 2 * (⨆ Q ∈ lawBall P.carrier.val eps, conditionNumber Q) ≤
          ENNReal.ofReal (19 * C) * conditionNumber P.carrier.val * (eps : ℝ≥0∞) ^ 2 ∧
        ENNReal.ofReal C * (eps : ℝ≥0∞) ^ 2 * (⨆ Q ∈ lawBall P.carrier.val (2 * eps),
          conditionNumber Q) ≤
          ENNReal.ofReal (19 * C) * conditionNumber P.carrier.val * (eps : ℝ≥0∞) ^ 2)
