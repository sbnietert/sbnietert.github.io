Lemma A.8 / scoped manuscript result

Kronecker trace identity

Proved in LeanPapers.WassersteinRegretS2S3.kroneckerFact

Manuscript statement

For matrices A,B,C with dimensions such that the following products are well-defined,
tr(ACBC⊤)=vec(C)⊤(B⊤⊗A)vec(C).

Formal statement

Exact signature from the verified source. Open the proof to follow each dependency.

lemma kroneckerFact {a b : ℕ}
    (A : Mat a a) -- @realizes \bA(real square trace factor)
    (B : Mat b b) -- @realizes \bB(real square Kronecker factor)
    (C : Mat a b) : -- @realizes \bC(arbitrary compatible rectangle)
    Matrix.trace (A * C * B * C.transpose) =
      Matrix.vec C ⬝ᵥ ((Matrix.kronecker B.transpose A) *ᵥ Matrix.vec C)
