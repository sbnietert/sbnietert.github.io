Scope of this snapshot

Scope: Sections 2 and 3 of the manuscript, together with their required preliminary and appendix results. Later computational and finite-sample statistical results are outside this verification snapshot. Formalization of the full paper is in progress.

Every estimator guarantee covers any admissible selection of minimizers. Uniqueness is not assumed.

Reproduce the checks

A standalone Lake project

Download and extract the Lean project. With elan installed, run the following inside the extracted directory.

lake exe cache get
lake build
lake env lean Check.lean
lake env lean ScopeChecks.lean

What the checks establish

The build checks proof terms in Lean. The two audit files print transitive axiom dependencies for the named results and the two proved convention predicates. These lists should contain only propext, Classical.choice and Quot.sound.

What you need

The exact toolchain and public dependency revisions are pinned in the project. The first build needs internet access, available library caches, and sufficient storage. Browsing this companion works without Lean or an internet connection.
